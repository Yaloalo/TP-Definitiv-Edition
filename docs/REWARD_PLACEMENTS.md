# Deliberate exploration reward placements

Assignments belong to this mod. Native check coordinates/original item IDs were
verified against the local Dusklight Randomizer catalogue. No runtime randomizer
is needed. Each named grant is finite and recorded per save slot.

New-save growth budget: 85 native heart fragments + 11 collection fragments +
14 curated treasure fragments = 110, or 22 shared blessings. Individual bugs
provide Gilded Thread for permanent upgrades. Existing growth is never deducted.

Craft = a Hyrule Craft Relic; Ancient = an Ancient Rune; Sunward and Mirror are
unique artifacts for Magic Armor upgrades. Full recipes and flask pacing are
in PROGRESSION_AND_WARD.md.
